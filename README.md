# Banking Management System

## 📌 Project Overview

The Banking Management System is a console-based Java application designed to simulate basic banking operations. It allows users to manage bank accounts and perform transactions while applying validation rules to maintain account accuracy.

## ✨ Features

- Create and manage savings and current accounts
- Deposit money into an account
- Withdraw money with balance validation
- Transfer money between accounts
- Check account balances
- View transaction history
- Generate a simple account statement
- Enforce minimum balance rules for savings accounts
- Handle invalid input and transaction errors

*Only retain the features that are implemented in your code.*

## 🛠️ Technologies Used

- Java
- Object-Oriented Programming (OOP)
- Java Collections Framework
- Exception Handling
- Scanner for console input

## ▶️ How to Run

1. Clone or download this repository.
2. Open the project in Eclipse or another Java IDE.
3. Ensure the required JDK is installed and configured.
4. Run the `Main.java` file.
5. Follow the console menu to perform banking operations.
